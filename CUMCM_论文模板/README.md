# 2026 全国大学生数学建模竞赛 LaTeX 模板（去广告修正版）

本目录基于原 `cumcmthesis` 模板整理，已完成以下修改：

- 删除公众号、二维码、QQ群、淘宝、培训推广和第三方导流内容；
- 将竞赛标题、示例日期、类文件版本和格式说明更新为 2026 年；
- 按 2026 年官方论文格式规范更新正文页数、电子版、匿名和支撑材料要求；
- 将代码框、提示框、编号页分隔线及示例三线表的过粗边界统一调细；
- 提供可直接填写的 `template_2026.tex`，并保留完整用法示例 `example.tex`；
- 使用 XeLaTeX 编译并重新生成无广告的示例 PDF。

## 文件说明

- `template_2026.tex`：参赛论文起始模板，建议从此文件开始填写。
- `example.tex`：包含常用排版功能的完整示例。
- `cumcmthesis.cls`：模板类文件。
- `example.pdf`：由修正版源码编译得到的无广告示例。
- `figures/`：示例使用的非推广图片。

## 编译

请使用 XeLaTeX：

```text
xelatex template_2026.tex
xelatex template_2026.tex
```

电子版提交时，使用：

```latex
\documentclass[withoutpreface,bwprint]{cumcmthesis}
```

`withoutpreface` 会移除承诺书和编号专用页，使电子版第一页为摘要专用页。

## 2026 年格式检查要点

- A4 纸，上下左右页边距至少 2.5 cm。
- 纸质版第一页为承诺书，第二页为编号专用页，第三页为摘要专用页。
- 摘要原则上不超过一页，并从摘要页开始以阿拉伯数字连续编页码。
- 正文不要目录，正文不超过 30 页；附录页数不限。
- 电子版论文为单独的 PDF 或 Word 文件，不超过 20 MB，不含承诺书和编号专用页。
- 摘要、正文、附录和支撑材料不得出现参赛者身份、学校或赛区信息。
- 附录应包含支撑材料文件列表以及全部完整、可运行的源程序；无程序或无支撑材料时按官方规范明确说明。
- 人工智能工具的使用与声明须遵守竞赛期间有效的全国组委会规定。
