# 大纲模板：期刊 IMRaD（通用）

> 用法：复制到工作区，用 `versioned_write.py` 落盘为 `outline_v*.md`。每节 Claim / Evidence / Link / Budget 四行填；填完按 `paper-outline` 第 3 步 gate 自检。
> 期刊铁律以目标 venue 的作者指南为准：先钉 venue spec（栏宽、字数/页数上限、引用体例、图表政策），再分配预算。

## Section: 0 Title / Abstract / Keywords

**Claim:** [贡献一句话 + 关键结果数字]

**Evidence:** [正文核心图/表编号]

**Link:** [摘要断言正文全有对应]

**Budget:** [按 venue 字数上限]

## Section: 1 Introduction

**Claim:** [研究缺口 + 本文贡献 + 路线图]

**Evidence:** [文献缺口表（`literature-review`）]

**Link:** [引出方法节]

**Budget:** [约 15–20%]

## Section: 2 Methods / Model

**Claim:** [方法断言：模型形式 + 假设 + 求解路径]

**Evidence:** [公式推导 / 算法 / 代码，或 TBD → 主技能]

**Link:** [输出 feed 结果节]

**Budget:** [约 25–30%]

## Section: 3 Results

**Claim:** [结果断言：主结果 + 对比基线]

**Evidence:** [图/表（`figure-table-generation`），每数可追溯]

**Link:** [结果 feed 讨论]

**Budget:** [约 25–30%]

## Section: 4 Discussion

**Claim:** [解释 + 局限 + 与文献关系]

**Evidence:** [检验/敏感性分析回指]

**Link:** [收束到结论]

**Budget:** [约 15–20%]

## Section: 5 Conclusion

**Claim:** [贡献重述，不开新断言]

**Evidence:** [前文回指]

**Link:** [—]

**Budget:** [约 0.5 页]

## Section: References

**Claim:** [文内全标注，体例按 venue]

**Evidence:** [TBD → `citation-bibliography`]

**Link:** [—]

**Budget:** [按 venue 排]

## Section: Appendix / Supplementary

**Claim:** [冗长推导 + 程序 + 补充图表]

**Evidence:** [TBD → 程序清单 + 运行验证]

**Link:** [—]

**Budget:** [按 venue 政策]
