# 国赛 2026 格式合规检查单（2026 年修订稿）

> 来源：cumcmthesis v2.7 + 官方《论文格式规范（2026 年修订稿）》《参赛规则（2026 年修订稿）》。
> 正式提交前以全国组委会和所在赛区最新通知为准，本单不替代官方文件。

## 纸张与版式

- [ ] A4 纸，上下左右页边距至少 2.5cm（`cumcmthesis.cls` 已设 25mm，不动）。
- [ ] 左侧装订预留，打印后检查不压字。

## 字体与编译

- [ ] 强制 XeLaTeX（推荐 `latexmk -xelatex`，至少编两遍）；`cls` 在其他引擎下直接报错。
- [ ] 字体：西文 `Times New Roman` + `Arial`，中文 `simkai.ttf`（楷体）+ `simsun.ttc`（宋体）。
- [ ] 缺官方字体不阻断编译：`cumcm-fonts.sty` 自动回退（Songti SC / Noto Serif CJK SC / Fandol）。
- [ ] 要官方原字形才需一次安装：从 Windows 机器（`C:\Windows\Fonts`）取回两文件，
  跑 `python assets/scripts/setup-fonts.py --copy-from <目录> --dest userfonts --out report.json`。
- [ ] 日志中字体替换警告逐个认领，不留未认领的替换。

## 页面结构

- [ ] 纸质版第一页承诺书、第二页编号专用页、第三页摘要专用页（默认构建自动生成）。
- [ ] 电子版构建用 `[withoutpreface,bwprint]`，第一页必须为摘要页，不含承诺书/编号专用页。
- [ ] 摘要原则上不超过一页；从摘要页起以阿拉伯数字从 1 连续编页码。
- [ ] 正文不要目录（`\tableofcontents` 保持注释），正文不超过 30 页；附录页数不限。

## 电子版

- [ ] 单独的 PDF 或 Word 文件，不超过 20MB，不压缩。
- [ ] 国赛终稿以 PDF 为准，DOCX 只做过程协作稿。

## 匿名

- [ ] 摘要、正文、附录、支撑材料不得出现参赛者身份、学校、赛区信息。
- [ ] 提交前全文 grep 学校、姓名、赛区、报名号，零命中（含附录代码注释）。

## 参考文献

- [ ] 引用他人或公开资料（含网上资料）文内 `\cite` 标注 + 文末规范列出。

## 附录与支撑材料

- [ ] 附录列出支撑材料文件列表（文件名、格式、用途）；无支撑材料时明确写“本论文没有支撑材料”。
- [ ] 附全部完整、可运行源程序，结果与论文相符；无程序时明确写“本论文没有用到程序”。

## 智能工具声明

- [ ] 人工智能工具使用声明按竞赛期间有效的组委会规定填写；未使用也明确声明。

## 三线表线宽（本模板约定）

- [ ] `\toprule[0.8pt]` / `\midrule[0.5pt]` / `\bottomrule[0.8pt]`，不过粗。
