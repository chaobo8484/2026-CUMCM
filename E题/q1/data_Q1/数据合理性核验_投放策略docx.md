## 3. 方法合理性点评

1. **口径正确**：先汇总再相除（Σ消费/Σ点击），避免“比率的平均”失真；日度聚合与明细源核验差异为 0。
2. **CPA 作为公司级代理**：附件无注册归因，原文明确不下沉到单元，**方法诚实**。
3. **星期/趋势混杂**：原文已用同星期对照与回归控制，处理得当。
4. **滞后相关需谨慎**：消费与注册均含强周周期与趋势，0–7 日相关（尤其 6–7 日回升）受周周期影响，原文已指出“不能解释为广告一周后再生效”，**判断正确**。
5. **自相关**：DW≈0.81/0.77 提示正自相关，原文改用 HAC 稳健标准误，**处理正确**。
6. **模型选择**：模型1 与模型2 的 adjR²/AIC 差异很小，且滞后1日不显著，选模型1 作为主模型、模型2 作稳健性检验，**合理**。

## 4. 核验复现方式

复算脚本逻辑（等效于仓库 `verify_q1_time_data.py` + `time_strategy.py`）：
1. 读 `附件1.xlsx` 的 Sheet1/Sheet2，日期解析后按日求和；
2. Sheet2 按日连接，构造 CTR/CPC/CPA；
3. 假日效应：`HE = 假日日均值 / 同星期±4周“正常”日对照均值 − 1`；
4. 回归：`ln(R₊₁) ~ ln(C₊₁) + t + 星期哑变量 + 放假哑变量(+ ln(C₋₁))`，Newey–West。

**结论：原文可用于论文，但表1列名、表4数值需按当前口径重算并统一 HAC 设置。**
