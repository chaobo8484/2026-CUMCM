## 一、一句话总览

> Q2 做的事：把 **2227 条「方案—推广单元—关键词」记录**，先剔出 **890 条无效词**，再对 **1337 条活跃记录**用**四指标等权 TOPSIS** 算综合效益得分 $S$，最后与**成本（全年消费额）**做二维交叉，分成**黄金 / 重点 / 潜力 / 问题 / 无效**五类。

**要传达给评委的三句话**：
1. 关键词结构**极度失衡**：**39.96% 的词（890 条）全年零消费零点击**；

3. 分类**稳健**：三组权重下 **86.16%** 的活跃记录类别不变。

## 三、8 张图逐张说明

### Q2-1 成本效益四象限　`Q2-1_成本效益四象限.png`

- **画的是什么**：散点图，横轴 $\ln(1+\text{全年消费额})$、纵轴综合效益得分 $S$；四类分色，**黑边点＝边界敏感词**；两条虚线是 $C_{\text{thr}}=8.06$ 与 $S_{\text{thr}}=0.3193$；四角标注象限名。
- **怎么读**：点越靠**左上**越好（低成本高效益）；越靠**右下**越差（高成本低效益）。
- **建议位置**：**正文主图**（这是 Q2 的"门面图"，一图讲清分类逻辑）。
- **一句话解读**：点**密集聚集在中间偏右上**，左侧（低成本）区域词很少 → 说明"便宜又高效"的词天然稀少。
- ⚠️ **必须注明**：纵轴 $S$ 是 **TOPSIS 相对得分**，不是绝对效益；横轴做了对数变换。

### Q2-2 五类数量占比　`Q2-2_五类数量占比.png`

- **画的是什么**：横向条形图，五类各自的记录条数与占比。

## 五、论文中**必须注明**的 4 个方法学问题

> 这 4 条来自 `data_Q2/Q2问题清单.md`，是评委最容易质疑的点，**必须主动写**，不要等被问。

### ⚠️ P1-1（最严重）黄金词盘子极小、依赖小样本

| 事实 | 数值 |
| :--- | ---: |
| 黄金词合计消费 | **645.8 元**（仅占全年 **0.0453%**） |
| 黄金词点击量中位数 | **2 次** |
| 点击量 ≤ 3 的黄金词占比 | **72.4%** |
| 黄金词留存率均值 | 0.759（全体活跃仅 0.266） |

> 这 225 条"低成本高效益"词的"高效益"，主要来自 **1–2 次点击下的极端留存/浏览深度**，统计上不可靠。且经济盘子只有 646 元。
> **论文必须写**：这是**相对分类**，不代表可大规模扩量；Q3 中黄金词预算合计仅 **40.4 元**，正是这个原因。
> 💡 **建议**：补一个"**最小点击门槛（≥5 或 ≥10）**"下的对照分类，或用**收缩估计**做稳健性。

### ⚠️ P1-2 名义等权，实质由"留存"主导

| 秩相关 | Spearman |
| :--- | ---: |
| $S$ ~ 留存 | **0.877** |
| $S$ ~ 时长 | 0.723 |
| $S$ ~ 浏览深度 | 0.637 |
| $S$ ~ 点击规模 | 0.465 |

> 等权 TOPSIS 的排序**主要由留存决定**，与"四维同等重要"的说法不符。
> **论文必须写**：要么承认"等权指标 ≠ 等权影响"，要么给出秩标准化后的对照。

### ⚠️ P1-3 成本与效益正相关 → 四类不均衡是必然

$\text{Spearman}(\text{消费额}, S) = \mathbf{0.486}$。

> 高成本词往往也高效益，"便宜又高效"的黄金词天然稀少。所以四类数量是 **225/444/442/226** 而**不是各约 25%**。
> **论文必须写**：一句话解释四类失衡的机理，否则会被质疑"分类不合理"。

### ⚠️ P1-4 两条异常记录未落地标记

序号 **495、2113** 两条"零消费零点击但有 1 次浏览"，docx 要求"保留原值并**标记口径待核查**"，但当前产出**没有该标记列**。

> **建议**：在 `q2_record_clean.csv` 加一列 `口径待核查`（顺带做，成本极低）。
